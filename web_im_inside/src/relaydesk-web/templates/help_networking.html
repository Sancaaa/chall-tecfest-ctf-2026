Networking Configuration Guide

Architecture documentation for internal cluster communication, DNS resolution patterns, and service port allocations within the private VPC.

Internal DNS Resolution Standard

VPC Zone: *.svc.local

In order to prevent exposure to external networks, all private microservices inside the cluster communicate through dedicated internal Docker networks. Namespaces are resolved automatically using the private DNS zone format:

<service-alias>.svc.local

For example, a service registered under the alias example-svc in the service catalog resolves internally to example-svc.svc.local.

Testing Private Endpoints

Diagnostic Method

Because internal microservices do not publish ports to the public host or reverse proxy, operators must use the built-in API Connection Tester to send diagnostic requests from within the gateway network.

Construct target URLs using the internal hostname and port:

http://<service-alias>.svc.local:<port>/

The proxy forwards your request, including any configured custom HTTP headers and JSON bodies, and displays the complete raw response for analysis.
